DockKick guide

Set up your shortcuts once, then use them from the panel.

1. Keep DockKick close

Open the app from Start and pin its icon with Windows' normal taskbar menu. The icon shows and hides the panel. Escape, the close icon and clicking outside hide it; Exit in the tray stops the resident app.

2. Add applications

Use + in Applications. Search the picker or Browse for an .exe or .lnk. DockKick asks Windows to open it: an .lnk retains its target, arguments and working directory. App names are editable aliases.

3. Reuse text

Add up to ten .txt or .md files in Texts to copy. An alias changes the shortcut label, never the file name. Clicking an item reads and copies its current content, including line breaks. The eye opens the original in its default app. Nothing is pasted automatically.

Files up to 2 MiB and a 4 MiB Unicode clipboard budget are supported. A failed read or exceeded limit never publishes a partial result.

4. Add folders

Use + in Locations and choose a folder. Its shortcut opens File Explorer. The minus removes only the DockKick shortcut, with confirmation, never the original.

5. Arrange and personalize

Hold an item for about 150 ms, then drag within its section. Small pointer movement during the hold is allowed. The hand and guide show the move. In Settings, use the dotted grip and save with the disk icon.

General brings together Windows startup, language, theme and optional in-session scroll retention. The first launch detects the system language and theme. Each section scrolls independently.

If the original changes

If a renamed or moved destination cannot be found, the shortcut is kept. Open Manage and select its new location. DockKick does not move, rename or substitute your files to repair it.
