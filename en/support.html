Quick access to your apps, reusable text and folders on Windows 11.

Getting started

Open DockKick from Start and use + in a section to add an app, a .txt/.md file or a folder. Pin DockKick to the taskbar using Windows' normal pin menu to show and hide the panel with one click. Manage opens that section in Settings.

What happens when I copy a text file?

Its current text, including line breaks, is copied to the system clipboard. Nothing is pasted automatically and the original is not edited. The alias names the DockKick shortcut. The eye opens the original; the minus removes the shortcut only. The file limit is 2 MiB, with a 4 MiB Unicode clipboard budget.

Windows clipboard history

DockKick opens the native Win+V feature. Try Win+V directly if it does not appear. Windows manages availability and any synchronization. DockKick does not store a separate history.

Reordering and appearance

Press and hold a shortcut briefly, then drag it within its section. Settings uses the dotted grip. Choose your language and light/dark theme in General, then save. The first run detects the Windows language/theme. Each section scrolls independently; scroll resets when hidden unless you choose to remember it during the current session.

Startup, updates and exit

Startup is optional in Settings → General and in Windows startup options. Store manages updates. The close button and Escape hide the panel; Exit in the tray stops DockKick. If an opening immediately after an update is temporarily unavailable, wait a few seconds and try again.

Report a problem

Contact Root Digital support. Include the DockKick version, Windows version, display scale, steps and any error message. Use generic examples and redact screenshots. Do not send passwords, private clipboard contents, personal paths or a complete unredacted configuration.

Supporting the project is optional: Ko-fi. It does not unlock features or affect support availability. Microsoft is not the fundraiser or sponsor.

A file, app or folder was moved or renamed

DockKick keeps the shortcut, alias and order. If the destination is unavailable, a notice explains how to select it again in Settings. Use the section's Manage pencil, then the folder button to change the destination. Remove the shortcut if you no longer need it; it is not removed automatically.

A Windows-registered app can keep its identifier when its display name changes. Windows may also resolve some .lnk targets after a rename. DockKick respects that mechanism and does not search for or substitute a different original.
