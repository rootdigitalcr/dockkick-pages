Scope and limits

What DockKick does and what Windows manages.

Shortcuts, not originals

Aliases and destinations are saved. Removing, ordering or renaming a shortcut never deletes or renames the original file, folder or application. Moved targets are explicitly managed in Settings.

Native history

Win + V belongs to Windows. Enablement and synchronization depend on the system. DockKick does not replace that history or copy it into its own database.

Windows 11 x64

Public distribution is planned as MSIX through Microsoft Store. No standalone installer is offered here. Windows manages installation, updates, permissions, focus and folder opening.

Translations

The twenty built-in languages are text data. Optional JSON translations cannot add actions, styles or code. The user folder and its guide can be opened from General.

Voluntary support

Ko-fi is an external option to support development, not the support channel. It does not unlock features. Microsoft is not the fundraiser or sponsor. Never send private data to a public issue.
