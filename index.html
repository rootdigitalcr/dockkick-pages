DockKick · Windows 11

Your shortcuts, close at hand.

Open apps and folders, copy reusable text and reach native clipboard history from a compact panel.

Get startedFind help

Applications

Add apps known to Windows or choose an executable or shortcut.

Texts to copy

One click copies the current content of a .txt or .md file. It does not paste automatically or edit the original.

Clipboard

Open Win + V, the history managed by Windows. DockKick does not create a separate history database.

Locations

Keep folder shortcuts and open them in File Explorer. Removing a shortcut never deletes the folder.

Distribution

Public distribution is being prepared for Microsoft Store. These pages contain documentation, not installers or the app's source code.

The interface includes 20 languages, light and dark themes, and optional Windows startup.
