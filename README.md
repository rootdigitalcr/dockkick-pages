Public help and privacy pages for DockKick by Root Digital. This repository contains documentation only, not the app source, private configuration or installers.

Enable GitHub Pages from main / (root). Open https://rootdigitalcr.github.io/dockkick-pages/ after deployment. Public support: https://github.com/rootdigitalcr/dockkick-pages/issues/new/choose

Privacy/security contact: info@root-cr.com. Do not attach private data to public issues.
