Alcance y límites

Qué hace DockKick y qué gestiona Windows.

Accesos, no originales

Se guardan alias y destinos. Quitar, ordenar o cambiar un alias no elimina ni renombra archivos, carpetas o aplicaciones. Los destinos movidos se gestionan de forma explícita desde Configuración.

Historial nativo

Win + V pertenece a Windows. Su activación y sincronización dependen del sistema. DockKick no sustituye ese historial ni lo copia a una base de datos propia.

Windows 11 x64

La distribución pública prevista es MSIX mediante Microsoft Store. No se ofrece aquí un instalador suelto. Windows controla instalación, actualizaciones, permisos, foco y apertura de carpetas.

Traducciones

Los veinte idiomas integrados son datos de texto. Las traducciones opcionales en JSON no pueden añadir acciones, estilos ni código. La carpeta del usuario y su guía se abren desde General.

Apoyo voluntario

Ko-fi es una opción externa para apoyar el proyecto, no el canal de soporte. No desbloquea funciones. Microsoft no es el recaudador ni patrocinador. Nunca envíes datos privados a un issue público.
